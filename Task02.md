# Задание 2. Симуляция парсинга NMEA в Python

## Цель работы

Разработать программный модуль на языке Python для разбора GPS-сообщений формата GPRMC, проверки контрольной суммы, извлечения навигационных данных и определения достоверности координат.

---

## Теоретические сведения

Протокол NMEA 0183 используется для передачи навигационной информации между GPS-приёмником и полётным контроллером. Одним из наиболее распространённых сообщений является GPRMC (Recommended Minimum Navigation Information).

Пример сообщения:

```text
$GPRMC,123519,A,5530.1234,N,03728.4567,E,0.5,45.0,210426,,*6E
```

Структура сообщения:

| Поле | Значение | Описание |
|--------|--------|--------|
| GPRMC | Тип сообщения | Recommended Minimum |
| 123519 | Время UTC | 12:35:19 |
| A | Статус | A – данные валидны |
| 5530.1234 | Широта | DDMM.MMMM |
| N | Направление | Север |
| 03728.4567 | Долгота | DDDMM.MMMM |
| E | Направление | Восток |
| 0.5 | Скорость | Узлы |
| 45.0 | Курс | Градусы |
| 210426 | Дата | 21.04.2026 |

---

## Вычисление контрольной суммы

Контрольная сумма вычисляется операцией XOR над всеми символами между символами "$" и "*".

Для первой строки:

```text
GPRMC,123519,A,5530.1234,N,03728.4567,E,0.5,45.0,210426,,
```

Получено:

$$
CS = 6E_{16}
$$

Полное сообщение:

```text
$GPRMC,123519,A,5530.1234,N,03728.4567,E,0.5,45.0,210426,,*6E
```

Для второй строки:

```text
GPRMC,123520,V,,,,,,,210426,,
```

Получено:

$$
CS = 25_{16}
$$

Полное сообщение:

```text
$GPRMC,123520,V,,,,,,,210426,,*25
```

## Функция проверки достоверности координат

Для проверки используется поле статуса.

Если:

```text
A
```

то координатам можно доверять.

Если:

```text
V
```

то координаты считаются недостоверными.

Функция проверки:

```python
def gps_is_valid(sentence):
    fields = sentence.split(',')

    if len(fields) < 3:
        return False

    return fields[2] == 'A'
```
